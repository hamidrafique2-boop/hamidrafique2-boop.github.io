## `> this site`

<table>
<tr><td>

**Design system:** *Signal Discipline* — warm charcoal/paper neutrals, a
single burnt-orange accent, and a persistent SVG "signal trace" that
redraws on scroll. Built around the idea both CTF and SOC work share:
finding the real signal in the noise.

**Stack:** zero-build static site — `index.html` / `style.css` /
`script.js`. Fraunces + Inter + IBM Plex Mono. Dark/light theme
(persisted, no flash, respects OS preference). Fully keyboard-navigable,
`prefers-reduced-motion`-safe, no horizontal scroll from 320px up.

**Sections:** Hero → About → Capabilities → Fractured Signal (flagship)
→ Field Record → Credentials → Contact
